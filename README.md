# Кладбище мистера Королёва (`gravemogill`)

**[Играть в браузере (GitHub Pages)](https://omich55zz-debug.github.io/gravemogill/)** · **[Скачать Android APK (debug)](https://omich55zz-debug.github.io/gravemogill/gravemogill-debug.apk)**

> Чтобы ссылки заработали, владельцу репо нужно один раз включить GitHub Pages: Settings → Pages → Source → Deploy from a branch → `gh-pages` / `/`.

Top-down тайм-менеджер / симулятор кладбища для Android и iOS.

Главный герой — **мистер Королёв**, превративший родовые земли в место последнего прибежища.
К нему обращаются родственники усопших, и игроку нужно обустроить могилу так, чтобы она
соответствовала заказу — не скромнее и не пышнее, чем может позволить себе семья, и уложиться
в отведённые дни.

- Движок: [Phaser 3](https://phaser.io/) + TypeScript + Vite
- Оболочка для мобильных: [Capacitor](https://capacitorjs.com/) (Android, iOS)
- Графика: процедурно сгенерированный пиксель-арт (отрисовывается в рантайме — ассетов в `/public` нет)

## Механики

- **Приём заказов.** В панели слева появляется новый клиент: имя покойного, тир (Скромный/Достойный/Пышный), бюджет, допустимый диапазон «роскоши» и срок в днях. Можно принять или отказать.
- **Копание могилы.** Встаньте на пустой участок (обозначен колышками по углам) и нажмите **Действие / Пробел** → «Копать могилу» (−10 ₽).
- **Надгробия, цветы, фонари, оградки, статуи.** Каталог из 13+ предметов разных уровней. У каждого есть стоимость и балл роскоши.
- **Имя на надгробии.** Обязательный шаг перед сдачей заказа.
- **Сдача заказа.** Подсчитывается суммарная роскошь могилы + бонус от соседних дорожек (+3 ₽ за клетку). Оплата:
  - роскошь в диапазоне `[min, max]` заказа → **100%** бюджета (идеально);
  - ниже минимума → **≈55%** (скромновато);
  - выше максимума → штраф по избытку (семья не может заплатить за излишнюю пышность);
  - просрочен дедлайн → **≈40%**.
- **Дорожки.** Кладутся на траву за 8 ₽ и приносят +2 ₽/день пассивного дохода, плюс бонус при сдаче соседней могилы.
- **Кошка-помощник.** Бродит по кладбищу и периодически откапывает кристалл — подберите его, чтобы получить 25–75 ₽.
- **День/ночь.** Один игровой день ≈ 90 секунд реального времени. На рассвете нового дня проверяются дедлайны и выплачивается доход от дорожек.

## Управление

- Клавиатура: **WASD** или стрелки — движение, **Пробел / E** — действие на текущей клетке.
- Тач/мышь: виртуальный стик снизу-слева, кнопка **Действие** снизу-справа.

## Разработка

Требуется Node.js 20+.

```bash
npm install
npm run dev        # локальный dev-сервер (http://localhost:5173)
npm run build      # production-сборка в dist/
npm run typecheck  # проверка типов
```

## Сборка под Android / iOS (Capacitor)

Первичная инициализация (однократно):

```bash
npm run build
npx cap add android   # добавит папку android/
npx cap add ios       # добавит папку ios/  (требуется macOS + Xcode)
```

Далее при каждом изменении кода:

```bash
npm run cap:sync            # пересобрать web + скопировать в нативные проекты
npm run cap:open:android    # открыть в Android Studio
npm run cap:open:ios        # открыть в Xcode (только на macOS)
```

Быстрый запуск на подключённом устройстве/эмуляторе:

```bash
npm run cap:run:android
npm run cap:run:ios
```

Нативные папки `android/` и `ios/` добавляются локально и не коммитятся в репозиторий
(см. `.gitignore`).

## Структура

```
src/
  main.ts              # вход, конфиг Phaser.Game
  scenes/
    BootScene.ts       # генерация всех текстур
    MenuScene.ts       # главное меню
    GameScene.ts       # игровая логика, тайлы, сущности
    UIScene.ts         # HUD, модалки, виртуальный стик
  systems/
    Economy.ts         # казна
    TimeSystem.ts      # дни/часы, события
    OrderSystem.ts     # заказы: генерация/приём/сдача
  entities/
    Player.ts          # мистер Королёв
    Cat.ts             # кошка-помощник
  data/
    catalog.ts         # каталог предметов (надгробия, цветы, …)
    config.ts          # игровые константы
    names.ts           # генератор имён клиентов
  utils/
    grid.ts            # тайловая сетка и клетки
    sprites.ts         # процедурная отрисовка пиксель-арта
```

## Дальнейшие шаги

- Подключить готовые тайлсеты (например, с [itch.io](https://itch.io/game-assets/free/tag-pixel-art)) — заменить ключи текстур в `sprites.ts`.

- Сохранения (localStorage/@capacitor/preferences).
- Локализация (ru/en) — все строки сейчас встроены.
- Балансировка экономики: цены, штрафы, длительность дня.
